# Falcon Premium Bot v2 — Latest Update

## Owner mention reaction
The crown reaction is triggered **only when a message directly mentions a primary bot owner**. If the message is a reply/reference, the crown reaction is not added.

## Existing systems preserved
- Giveaway commands were not modified.
- No-prefix remains user-based and global across guilds.
- Setup, Extra Owner, customization, lockdown, AutoMod and Anti-Nuke systems remain in place.
